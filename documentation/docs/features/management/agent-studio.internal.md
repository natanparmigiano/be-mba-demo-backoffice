# Agent Studio

:::warning Internal documentation

This page is part of the internal portion of the documentation. It includes the
Management application and its administrative and integration features. For
external sharing, this page will not be available.

:::

Agent Studio edits organization-scoped AGTX projects and the resources bundled
with them.

## What it covers

- Editing project manifests and MCP definitions.
- Configuring remote connectors.
- Managing packaged files.
- Autosaving projects and importing or downloading packages.
- Using assisted authoring tools for project content.
