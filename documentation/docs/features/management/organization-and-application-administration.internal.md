# Organization and application administration

:::warning Internal documentation

This page is part of the internal portion of the documentation. It includes the
Management application and its administrative and integration features. For
external sharing, this page will not be available.

:::

Privileged administration controls organizations, application users, and
access across MBA Desk.

## What it covers

- Organization membership and access.
- Application users and roles.
- Password resets, session revocation, bans, and impersonation.
- Confirmed organization deletion.
