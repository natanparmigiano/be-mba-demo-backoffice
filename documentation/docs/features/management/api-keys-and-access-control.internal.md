# API keys and access control [INTERNAL]

:::warning Internal documentation

This page is part of the internal portion of the documentation. It includes the
Management application and its administrative and integration features. For
external sharing, this page will not be available.

:::

API keys provide organization-scoped access to selected programmable
capabilities.

## What it covers

- Creating and revoking organization API keys.
- Restricting permissions to selected functions and MCP packages.
- Reviewing the functions currently exposed by an authorized package.
