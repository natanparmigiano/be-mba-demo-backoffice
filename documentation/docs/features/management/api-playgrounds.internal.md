# API playgrounds

:::warning Internal documentation

This page is part of the internal portion of the documentation. It includes the
Management application and its administrative and integration features. For
external sharing, this page will not be available.

:::

The API playgrounds provide forms for running supported WhatsApp and agent
operations and inspecting the resulting requests and responses.

## What it covers

- Agent, registration, messaging, media, marketing, and QR operations.
- Components, Flows, templates, analytics, moderation, and subscriptions.
- WABA and webhook operations.
- Request and response inspection and Postman collection generation.
