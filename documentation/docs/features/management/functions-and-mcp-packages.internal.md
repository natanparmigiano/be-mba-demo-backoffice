# Functions and MCP packages

:::warning Internal documentation

This page is part of the internal portion of the documentation. It includes the
Management application and its administrative and integration features. For
external sharing, this page will not be available.

:::

Functions define custom operations, while MCP packages expose selected
functions together through authenticated endpoints.

## What it covers

- Defining typed function inputs and versioned JavaScript behavior.
- Testing functions and reviewing execution history.
- Selecting the functions included in an MCP package.
- Importing and exporting MCPX packages.
