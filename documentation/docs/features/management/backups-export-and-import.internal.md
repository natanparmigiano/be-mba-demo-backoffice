# Backups, export, and import

:::warning Internal documentation

This page is part of the internal portion of the documentation. It includes the
Management application and its administrative and integration features. For
external sharing, this page will not be available.

:::

These workflows preserve agent configuration and move it between supported
environments or organizations.

## What it covers

- Saving and restoring configuration backups.
- Exporting portable AGTX packages.
- Inspecting packages before import.
- Selecting configuration areas and supplying required files or credentials.
- Reviewing applied, skipped, and failed import stages.
