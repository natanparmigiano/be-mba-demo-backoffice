# Agent evaluations [INTERNAL]

:::warning Internal documentation

This page is part of the internal portion of the documentation. It includes the
Management application and its administrative and integration features. For
external sharing, this page will not be available.

:::

Agent evaluations run defined conversation scenarios and record how the agent
performed against their expectations.

## What it covers

- Reviewing and managing evaluation scenarios.
- Starting asynchronous evaluation runs.
- Monitoring run progress and completion.
- Reviewing scores, summaries, highlights, and failures.
