# Webhook visibility [INTERNAL]

:::warning Internal documentation

This page is part of the internal portion of the documentation. It includes the
Management application and its administrative and integration features. For
external sharing, this page will not be available.

:::

The webhook explorer provides a diagnostic view of events received and
processed for an organization's channels.

## What it covers

- Filtering events by channel and time range.
- Inspecting complete JSON payloads.
- Reviewing processing and total duration.
- Exporting event data for further analysis.
