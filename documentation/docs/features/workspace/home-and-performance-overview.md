# Home and performance overview

The Workspace home page summarizes activity for the selected WhatsApp channel
from the local MBA Desk database and provides entry points into the main
operational workflows. The overview remains available when provider analytics
cannot be loaded.

## What it covers

- Selecting the channel whose activity is displayed.
- Comparing conversation, contact, unread, queue, outbound-message, and
  delivery counters.
- Reviewing seven-day inbound/outbound activity and message-type charts.
- Comparing the share of agent and human outbound messages and the average
  delay from handoff to the first human reply.
- Comparing conversation assignments by team and by user.
- Refreshing message and delivery information on demand.
- Opening conversations, contacts, groups, and organization settings.
- Seeing when the displayed snapshot was generated.

Dashboard snapshots are cached for five minutes. Choosing **Refresh** bypasses
the current snapshot and replaces it with newly aggregated data.

Agent/human share, first-response time, and assignment rankings use the
append-only statistics events recorded after the statistics migration is
applied. Earlier activity is not backfilled, so these metrics begin empty and
become representative as new messages and handoffs occur.
