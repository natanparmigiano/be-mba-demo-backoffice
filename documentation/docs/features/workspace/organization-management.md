# Organization management

Organizations define the membership, branding, and data boundary used by the
Workspace application.

## What it covers

- Switching the active organization.
- Updating organization identity, logo, and primary color when authorized.
- Inviting, listing, and removing organization members.
- Accepting pending organization invitations.
- Renaming or deleting an organization when permitted.
