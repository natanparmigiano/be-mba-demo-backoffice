# WhatsApp inbox

The inbox displays direct and group conversations for the active organization,
including unread state and a chronological message and event timeline.

## What it covers

- Text, media, documents, voice notes, contacts, and locations.
- Reactions, interactive messages, timestamps, and delivery status.
- Loading earlier conversations and messages.
- Live updates for the inbox and open conversation.
- Sending supported messages while a person owns the conversation.
