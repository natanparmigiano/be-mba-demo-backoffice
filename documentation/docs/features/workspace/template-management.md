# Template management

The templates area manages WhatsApp message templates and their provider
approval lifecycle.

## What it covers

- Filtering templates by channel, name, category, language, and status.
- Previewing templates as WhatsApp messages.
- Creating and editing template components and parameters.
- Uploading supported example media.
- Reviewing approval, quality, rejection, and update information.
