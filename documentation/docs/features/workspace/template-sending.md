# Template sending

The sending workflow resolves an approved template for a recipient and records
the resulting delivery activity.

## What it covers

- Selecting a channel, recipient, approved template, and delivery API.
- Providing named or positional parameters and supported header media.
- Previewing the resolved message before sending it.
- Filtering send history by template, recipient, API, and delivery status.
